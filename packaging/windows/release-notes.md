bachi-motion 0.2.2（Windows）

下载 `bachi-motion-0.2.2-windows-x64.zip`，整包解压后双击 `bachi-motion.exe`。

- 打开的是程序自己的窗口，不用另外打开浏览器，也不用安装 Node 或 Chrome。
- 安装包里带了 Chromium 和 ffmpeg。解压之后不需要联网。
- 有显卡时，画面用显卡，编码按 NVIDIA NVENC、AMD AMF、Intel QSV 的顺序尝试。
- 没有显卡，或显卡初始化失败，或硬件编码失败时，自动改用 CPU，仍然可以出片。
- 成片在「视频\bachi-motion」。

请解压全部文件。只拷贝 exe 会缺页面、字体和 ffmpeg。

这个版本新增

- 预览更顺了
- 手顺编辑改成鼠标优先：点音符立刻换左右；框选后旁边可以直接选 1-2 / 2-1 / 2-2，也可以循环试听；谱面左右两端有箭头；「加入音符」右边可以勾选「分开小节」
- 滚奏增加「全 2-2」。16 / 24 / 32 分默认从第一颗起 2-2；躲开外刷只对 8 颗及以上的大串生效
- 滚奏绝对规则（自动滚奏和全 2-2 都一样，不滚奏不受影响）：四连 1-2-1、三连 2-1、12 分 1-2。12 分按前向间隔切，不会把下一串 16 / 24 / 32 的第一颗吃成正攻
- 变速按谱面 BPM×SCROLL：参考 BPM 用时间轴最高 BPM（例如里第六天魔王是 300）。关掉变速仍是等速。流速是单独的整体倍率，下限改到 0.5，默认仍是 1
- 可以按「全部谱面」一次看完整张谱
- 修了部分谱面开头音符飞掉的问题
