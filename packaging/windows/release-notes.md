bachi-motion 0.2.1（Windows）

下载 `bachi-motion-0.2.1-windows-x64.zip`，整包解压后双击 `bachi-motion.exe`。

- 打开的是程序自己的窗口，不用另外打开浏览器，也不用安装 Node 或 Chrome。
- 安装包里带了 Chromium 和 ffmpeg。解压之后不需要联网。
- 有显卡时，画面用显卡，编码按 NVIDIA NVENC、AMD AMF、Intel QSV 的顺序尝试。
- 没有显卡，或显卡初始化失败，或硬件编码失败时，自动改用 CPU，仍然可以出片。
- 成片在「视频\bachi-motion」。

请解压全部文件。只拷贝 exe 会缺页面、字体和 ffmpeg。

这个版本新增

- 导入或粘贴 TJA 后进入全自动；已经导入的自定义手顺，生成器仍然不能改写
- 缩小播放页时，标题不再盖住上方的手顺编辑器和「溯溯的鼓棒」
- 变速开关（勾选框在慢放和流速上面，默认开）：打开时画面跟谱面 `#SCROLL`（音符会突然变密/变疏、变快/变慢，后音可以追上前音）；关掉时等速练习，忽略 `#SCROLL`。`#BPMCHANGE` 只决定何时打到。流速 1.1、1.2 仍是单独的整体倍率。0.2.1 修正了 0.2.0 里变速按 BPM 等宽拍子显示的错误逻辑。
- 有谱面分歧时，点难度后再选普通、玄人、达人
- 四连 24分用 1-2-1（自动滚奏里也一样）；16夹24 和 12夹24 用 1-2
